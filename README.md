# Kinematics Datasets

This repository contains physics-based simulation and kinematics benchmark datasets for representation learning and identifiability evaluation.

## Datasets

### Wilberforce Pendulum
- Coupled translation and rotation dynamics.
- Continuous non-linear coordinates and energy-preserving or dissipative dynamics.
- Frame rendering and dataset pairing functionality.

### Double Pendulum
- Coupled two-link non-linear chaotic dynamics with RK4 numerical integration.
- Continuous angular coordinates and energy-preserving or dissipative dynamics.
- Image frame rendering and RealNVP flow mixing.
